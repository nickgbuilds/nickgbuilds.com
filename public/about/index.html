About

I build systems that I actually use. My homelab runs on a TrueNAS server in my home. It hosts my family's photo library, media streaming, game servers, network-wide ad blocking, and hardware monitoring. Every project on this site is something I depend on daily.

I'm drawn to infrastructure that's reliable, private, and mine. Not for ideology, but because I learn more from operating real systems than from following tutorials. When something breaks at 2 AM, that's when the real learning happens.

This site itself is self-hosted: plain HTML, CSS, and JavaScript, containerized with Docker, and served from the same TrueNAS box behind a Cloudflare Tunnel.
